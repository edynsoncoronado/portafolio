# Activity Steps

API para registrar actividades con pasos ordenados. Proyecto de práctica de SDD + TDD + hexagonal ligera (versión corta: sin base de datos ni API).

## Antes de nada
- Lee `docs/constitution.md` (reglas no negociables).
- Trabaja solo sobre la spec activa en `specs/<feature>/` y solo en la tarea que se te indique de `tasks.md`.

## Comandos
- Tests: `uv run pytest`

## Verificación obligatoria al terminar cada tarea
`uv run pytest` en verde. Marca la tarea en `tasks.md` y **detente**.

## No tocar
- `docs/constitution.md` y los `requirements.md` sin pedírmelo.
- No añadas dependencias.
